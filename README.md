# 6x6x6 Rubik's Cube Solver

A web app that scans a 6x6x6 cube with a phone camera and then walks you through the solution one turn at a time on a 3D model.

Work in progress. The app runs entirely in the browser (TypeScript, Vite, three.js); there is no backend.

## Develop

```
pnpm install
pnpm dev        # start the dev server
pnpm test       # run the test suite
pnpm build      # production build in dist/
```

See `docs/CONVENTIONS.md` for the cube model every part of the app shares.
